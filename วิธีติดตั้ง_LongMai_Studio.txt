━━ 1) Custom nodes → ต้องไปอยู่ในโฟลเดอร์ ComfyUI/custom_nodes/ ━━

วิธี A (แนะนำ) — ComfyUI Manager:
   เปิด workflow → Manager → Install Missing Custom Nodes → กดติดตั้งทุกตัว → รีสตาร์ต ComfyUI
   (Manager จะ git clone ลง custom_nodes/ และติดตั้งไลบรารีที่ต้องใช้ให้เอง)

วิธี B — git clone เอง:
   1. เปิด Terminal / Command Prompt ที่โฟลเดอร์ ComfyUI/custom_nodes
   2. รันคำสั่งทีละบรรทัด (โฟลเดอร์ที่ clone มาจะอยู่ใน custom_nodes/ เอง):
      git clone https://github.com/kijai/ComfyUI-KJNodes      ← เสียงแจ้งเตือน, Chunk / Low VRAM
      git clone https://github.com/pixaroma/ComfyUI-Pixaroma      ← สวิตช์กลุ่ม, LoRA loader, ป้ายหัว
      git clone https://github.com/yolain/ComfyUI-Easy-Use      ← ปุ่ม 🎲 seed
      git clone https://github.com/rgthree/rgthree-comfy      ← Any Switch
      git clone https://github.com/Adudeguyman/ComfyUI-Fantastic-MiniMaxH3-PromptBuilder      ← Media Loader
      git clone https://github.com/ethanfel/ComfyUI-H3-Prompt-IDE      ← ช่องเขียน Prompt
      git clone https://github.com/T8mars/comfyui-minimax-h3-audio-T8      ← Action Bridge, AV Decode
      git clone https://github.com/NikoDemon80/ComfyUI-H3-Motion-Context      ← (ไม่บังคับ — workflow ไม่ได้ใช้แล้ว)
      git clone https://github.com/LBH-123-AI/Comfyui_Minimax_h3_latent_Upscaler      ← อัปสเกล Stage 2
      git clone https://github.com/Fannovel16/ComfyUI-Frame-Interpolation      ← (ไม่บังคับใน V3 — V3 ใช้ NVIDIA แทน RIFE)
      git clone https://github.com/Zironic/H3-Optimizations      ← ช่องเลือกขนาด Stage 1 (Resolution Selector)
   3. ติดตั้งไลบรารีของ node (ต้องใช้ python ของ ComfyUI เอง ไม่ใช่ python ของเครื่อง):
      ComfyUI portable (รันจากโฟลเดอร์ custom_nodes):
         ..\..\python_embeded\python.exe -m pip install -r <ชื่อโฟลเดอร์>equirements.txt
      ComfyUI แบบ venv: เปิด venv ก่อน แล้ว  pip install -r <ชื่อโฟลเดอร์>/requirements.txt
      ตัวที่มี requirements.txt: ComfyUI-KJNodes, ComfyUI-Pixaroma, ComfyUI-Easy-Use, rgthree-comfy, ComfyUI-Fantastic-MiniMaxH3-PromptBuilder, comfyui-minimax-h3-audio-T8
      ComfyUI-Frame-Interpolation: เข้าโฟลเดอร์นั้นแล้วรัน  python install.py  (ด้วย python ของ ComfyUI)
   4. รีสตาร์ต ComfyUI

• ComfyUI-LongMai-Tools — ข้อยกเว้น: ใช้ "คัดลอก" ไม่ใช่ git clone / Manager
   ดาวน์โหลด repo ด้านบน (Code → Download ZIP) → แตกไฟล์ → คัดลอกโฟลเดอร์
   custom_nodes/ComfyUI-LongMai-Tools ไปวางใน ComfyUI/custom_nodes/
   ห้าม clone repo ของเราลง custom_nodes ตรงๆ (ComfyUI จะหา node ไม่เจอ) · ไม่ต้อง pip install
   ใช้ทำ 48 fps ตัดช็อตสะอาด / โหลด Stage 1 ที่บันทึกไว้ / Join Clips (Join Clips ต้องมี ffmpeg ในเครื่อง)
