# ภาษาไทยสำหรับ H3ZeroStudio

- `main.json`: ข้อมูล `H3ZeroStudio.ui` สำหรับเมนู คำบรรยาย tooltip และข้อความสถานะ และ `H3ZeroStudio.help` สำหรับคู่มือภายในโปรแกรม
- `nodeDefs.json`: ชื่อ คำบรรยาย และ tooltip ของโหนด ตามรูปแบบ locales มาตรฐานของ ComfyUI

หน้าตัดต่ออ่านข้อมูลจาก `/i18n` ของ ComfyUI ผ่าน `web/js/h3s_locale.js` ส่วนไฟล์ `h3s_i18n_th.js` และ `h3s_help_th.js` เป็นตัวเชื่อมเท่านั้น ไม่เก็บคำแปลซ้ำ

เลือก **Settings → Interface language → ไทย** ในหน้าตัดต่อ แล้วโหลดหน้าใหม่ หลังเพิ่มโฟลเดอร์ภาษาใหม่ครั้งแรกต้องเริ่ม ComfyUI ใหม่ด้วย เพราะ ComfyUI เก็บรายการภาษาไว้ในแคชฝั่งเซิร์ฟเวอร์

รักษาตัวแปร `{0}`, `{1}` และแท็ก HTML รวมถึงแท็กไฟล์อ้างอิงให้ตรงต้นฉบับ ชื่อโมเดล พารามิเตอร์ sampler, scheduler, เส้นทางไฟล์ และข้อความ prompt ของผู้ใช้ไม่ต้องแปล

ชุดคำแปลใช้คำแปลไทยที่ตรวจแก้แล้วร่วมกับการแปลภาษาอังกฤษเป็นไทยด้วย Argos ที่รันในเครื่อง คำอธิบายเฉพาะทางบางส่วนอาจต้องปรับถ้อยคำเพิ่มเติมเมื่อใช้งานจริง ตรวจความครอบคลุมและตัวแปรด้วย:

```powershell
node tests/thai_locale.mjs
```

การอัปเดตส่วนขยายอาจเขียนทับการเชื่อมตัวโหลดภาษา ควรสำรองโฟลเดอร์ `locales/th` และไฟล์ตัวโหลดที่แก้ไขไว้ก่อนอัปเดต
